## 已实现

| 内容 | 结果 |
| --- | --- |
| 保存与恢复 | 三个工作区统一下载/打开版本化 ZIP；保留源码、编辑、撤销/重做和 PNG 宽度。R 包含数据及用户导入的字体。打开项目不执行代码，用户点击运行后重放。 |
| 复现材料 | 原脚本、重放脚本、项目状态、依赖锁与许可证；R 附带资产和最终 PDF，Matplotlib 附带经校验的同源引擎。 |
| PNG | 默认宽 2400，允许 320–8192；按实际图幅比例导出，检查高度与总像素预算。修复大图幅被旧 DPI 下限放大的问题。 |
| 加载与重试 | 显示本次耗时、失败阶段与网络状态；重试保留输入。R 模块下载失败后可重新获取同一锁定版本。 |
| CI | PR 检查翻译、类型、单元测试及完整站点构建；主分支、merge_group、full-ci PR 和手动运行真实四引擎浏览器验收，保留失败证据。 |
| 首页 | 中文静态简介与工作台链接、canonical、Open Graph、Twitter 分享卡；切换语言同步标题与描述。图片复用现有宣传图。 |

格式、安全预算与复现边界的权威说明见 [在线项目与复现包](figweave-online-projects.md)。
本次没有修改上游桌面格式、认证、写回事务或自动更新渠道。
