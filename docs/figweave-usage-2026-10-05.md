# FigWeave 使用统计后台验收（2026-10-05）

用户授权建设后台，查看 FigWeave 的使用情况，并已授权同步 GitHub 和现有服务器。

独立服务 `services/figweave_admin`：WSGI + Gunicorn + nginx，SQLite 放在
`engine.config.data_dir()`。管理员独立登录；数据 API 默认拒绝未认证会话。
同源 POST、Secure/HttpOnly/SameSite Cookie、12 小时会话、密码派生与共享限流。
后台提供累计 / 今日 / 7、30、90 天趋势、引擎明细及每日 CSV。

口径必须分开：历史 nginx 记录只能证明页面请求，不能证明有多少真人或多少人
成功画图。实际成功绘图浏览器数来自明确同意后的随机标识；同一浏览器多次运行
只计一个浏览器，不同引擎的去重数不能相加。过去的实际使用人数无法补算。

在线统计有独立的三态、版本化同意，不继承桌面选择；默认不发送、不生成标识。
事件是闭表，只接受版本、随机 UUID 和有限事件/引擎；不接受脚本、文件名、路径、
图表、任意属性或 IP。服务端只保留浏览器标识的 HMAC。未来 nginx 访问日志省略
IP、查询串、来源与 User-Agent 原文；历史日志只提取日汇总。事件和后台关闭访问日志。

验证：

- 全部前端单测：286 文件、4164 用例通过。
- 类型检查 / Vite 构建 / Tailwind 扫描 / i18n 校验通过。
- 新服务及既有桌面认证、遥测隐私回归：104 个后端用例通过。
- Ruff 全仓 check 与 format 检查通过。
- 手工反证九项：去掉后台认证、同源检查、白名单、硬关闭、事件去重、日志去重、
  北京时区、撤回后的发送守卫、未选择不生成标识；变异均落在预期源码，每项测试
  非零退出。恢复源码并清理变异产生的 Python 字节码后，新服务 21 用例再次通过。

部署说明、统计限制与操作方法以 [后台说明](../services/figweave_admin/README.md) 为准。
