# 小红书发布文案

## 推荐标题

图画完了，还在让 AI 改图例？

## 正文（可直接发布）

用 AI 写 Python / R 画图，最磨人的有时候真不是画图，而是最后那几句：

“字体不要新罗马，换 Arial。”
“图例放左下角。”
“字号再小一点……对，再小一点。”

改动很小，自己懒得翻代码；继续补 prompt，又要来回等一轮。

所以我在做 FigWeave：让这些收尾工作可以直接在图上完成。

运行绘图脚本 → 在图里调整 → 导出结果和支持重放的脚本。
视频里演示的是实际 ggplot2 图：把图例拖到左下方、字号从 12 调到 10，再导出包含这些修改的 R 脚本。

我想保留的是 Python / R 绘图的可复现性，同时让最后的细节调整更直观。它连接的是绘图脚本和图形对象，不必每次都从导出的成品图重新修起。

现在有 Matplotlib、Plotly、pyecharts 和 ggplot2 工作台；默认中文，背景色也可以换。不同引擎的编辑和导出范围有区别，正在逐步完善。

在线体验：fig-weave.com
GitHub：eveque-dev/fig-weave

## 发布备注（不放正文）

- 配图/封面：使用短片首屏“图画好了，还在补 prompt？”；视频为 32 秒横版，只有音效、无人声。
- Arial 是痛点举例；本片实测演示的是 ggplot2 字号和图例显示偏移，不暗示每个引擎都具备同样字体控件。
- 不使用“所有拖拽都会自动改原始代码”的表述。R 导出保留原脚本并追加样式/偏移重放代码；Plotly/pyecharts 按当前配置重建图表。
- 不说 Illustrator 的矢量 PDF 放大会失真。若需要比较：Illustrator 适合通用矢量编辑，FigWeave 侧重脚本绘图工作流及可复现修改。
