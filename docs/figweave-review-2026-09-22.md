## 建议按这个顺序继续

### 1. 首次运行速度与加载反馈（高优先级）

本次冷缓存 Python 三库测试用了约 5.7 分钟；独立下载测量中 WASM 20 秒仅下载约 0.9 MB。
这只能代表本次客户端链路，不能当成全部用户性能数据。核心 WASM 原始体积约 9.6 MB。
本轮先加 gzip 和缓存。建议随后从中国大陆、香港两地测冷/热启动 p50/p95，再决定是否使用
阿里云 OSS/CDN 存放同版本、同哈希的运行时文件。R 核心仍访问锁定版本官方站点，建议做
独立的镜像清单、哈希校验及自托管，不能把 WebAssembly 包换成普通 PyPI/CRAN 包。
加载界面可以进一步显示真实下载字节/阶段耗时，而不是只有阶段名称。

### 2. Python 在线版结果导出与恢复（高优先级）

当前 Python 在线体验能改图、撤销、查看修改记录，但没有清楚的结果导出入口；R 已有三种导出。
应复用既有导出管线补齐 Python SVG/PNG/PDF 的能力声明与入口，并为刷新前丢失编辑提供提示。
会话恢复若增加持久化，需要明确用户选择与隐私边界，不应静默保存源码。

### 3. 可复现发布（高优先级）

本地目录是无 `.git` 的工作副本，无法可靠确认它相对线上提交的完整差异。本次版本应以源代码
快照 SHA-256 和 playground 指纹标识，不能伪称来自一个新 Git 提交。建议后续恢复开发仓库，
让 CI 构建、测试、源码包和发布清单绑定同一提交。继续使用 releases/current 原子切换。
已有线上版本目录可被其他用户写入（777/666），新版本应使用目录 755、文件 644。

### 4. 运维与首屏体积（中优先级）

- 主机提示仍有安全更新及待重启；同机承载其他站点，应另选维护窗口处理，不能直接重启。
- 首页 JS 约 700 kB（gzip 后约 235 kB），主要复用了完整 i18n/基础依赖。可以拆出首页实际
  使用的语言命名空间并保持同一翻译真源，不为首页复制一套文案库。
- 首页目前依赖客户端渲染。后续可预渲染中英文 HTML，完善分享图、canonical 与搜索收录。
- 继续收敛既有测试清理日志、R 输入非法值提示和手机小屏编辑能力说明。

## 部署与回滚

服务器既有 Ubuntu APT 源已经指向阿里云，无需更改全局源。HTTPS 与 certbot 定时续期已存在。
Nginx 旧配置备份：`/etc/nginx/sites-available/fig-weave.backup-20260922-ui`。
新站点目录以 `20260922-ui-<fingerprint>` 标识，旧目录保留。
回滚时将 `/var/www/fig-weave/current` 原子切回
`/var/www/fig-weave/releases/20260922-7bce7c1`；如需同时撤销压缩策略，恢复上述配置备份后
先 `nginx -t` 再 reload。无需修改或重启其他站点。
