# 在线项目与复现包

用户于 2026-10-02 明确授权项目保存、恢复、复现包和导出一致性改进。
这些能力属于 FigWeave 在线入口，不修改桌面文档 schema、写回事务或自动更新渠道。

## 保存与恢复

`保存项目` 下载 `.tavotto-online.zip`；`打开项目` 读取 ZIP，然后由用户显式点击
运行恢复。导入不执行 Python/R，不信任包内 HTML、JS、引擎或依赖文件。
当前会话不会自动写入 localStorage/IndexedDB，也不会上传项目。未保存编辑会触发
浏览器离开保护；下载成功提示只表示下载已发起，不能证明用户最终保留了文件。
项目是显式的本机文件备份，浏览器刷新后通过该文件恢复。

`project.json` 的 kind 与扩展名来自 `web/src/lib/brand.ts`；版本为 1。
保存引擎、原始文件名、当前源码、最后成功渲染的源码、当前编辑、撤销/重做记录、
PNG 宽度及资产索引；Charts 还保留尚未应用的标签和 JSON 配置草稿。源码草稿和图表对应的源码分别保留，避免把未运行的草稿
冒充当前图表。Matplotlib 保留选中的 figure stem 与 overrides；R 保留 PlotStyle；
Charts 保留原生图表配置。恢复继续使用既有引擎和文档写入口。

R 资产放在 `assets/`，记录名称、字体族和 SHA-256；读取时校验实际字节。
文件类型、字体结构及数量沿用 R 工作区校验。数据或字体改动后，先重新运行再保存，避免把旧图表和新资产混在一起。文件名不得含路径或控制字符。
项目 ZIP 和声明的解压总大小各限 128 MiB、100 个条目，JSON 限 16 MiB，
源码各限 256 KiB；拒绝重复条目、路径穿越、原型污染键及不兼容版本。
先完整校验再替换会话，损坏项目不会清空当前输入。

## 复现包

复现 ZIP 使用同一份项目编码器，加上原始脚本、重放脚本、依赖锁、许可证和说明。
草稿与最后渲染源码不同的时候，两份都保留。

| 引擎 | 重放方式 |
| --- | --- |
| Matplotlib | 在线重开；或安装 requirements.txt 后显式运行 replay.py。包内 engine.zip 经站点 manifest 校验，与在线引擎同源。 |
| Plotly / pyecharts | replay.py 重建编辑配置，source.py 保留原始数据处理。两者用途分别写在说明中。 |
| ggplot2 | assets 内文件放到 replay.R 旁，从该目录运行 Rscript replay.R；最终 PDF 也随包保留。 |

锁文件记录浏览器运行时和依赖版本，不是接收端的自动安装器。原生环境仍需安装
相应依赖；跨平台字体渲染可能不同，随机或联网脚本需要自行固定输入与随机种子。
字体再分发权限由用户确定；程序不会静默打包系统字体。

## 导出与加载

PNG 默认宽 2400 像素，允许 320–8192，按实际图幅比例算高度；高度不超过 8192，
总像素不超过 3200 万。R 从最终 PDF 栅格化，Charts 使用当前实际渲染比例；
Matplotlib 使用同一引擎的状态中立 PNG 导出，不加入或清空编辑历史。
此入口以像素尺寸为设置口径，不将该数字称为投稿 DPI。

加载计时和失败阶段只保存在界面内存，无分析 SDK 或遥测发送。
网络断开显示重连提示；重试保留源码、资产与已导入项目。

## 验收

`pnpm test` 验证尺寸预算、项目往返、校验和、解压预算和不兼容状态。
`pnpm build` 检查全部前端类型；完整站点由 `scripts/build_figweave_site.py` 构建。
`web/e2e/figweave-site.spec.ts` 使用真实四引擎检查运行、编辑、撤销、项目恢复、
复现 ZIP 和下载图像尺寸，以及首页与窄屏布局。

PR 运行翻译、单元测试、类型与全站构建；merge_group、full-ci PR、主分支和
手动触发运行独立构建的真实浏览器验收，失败保留 trace 与截图。
