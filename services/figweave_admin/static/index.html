统计口径与隐私

访问次数来自成功返回的页面请求，刷新会重复计数，机器人过滤并不完美，不能据此还原“多少个真人”。导出计数只包含 PNG / PDF 图像生成，源码、JSON 和项目包不计入。实际使用仅包含明确同意后的随机浏览器标识、入口/引擎、打开页面、成功绘图和成功导出。换设备、清理浏览器存储会产生新的标识。

不采集脚本、图表、文件名、项目、路径、图内文字、IP、地理位置或指纹；不使用第三方分析服务。历史日志只提取按日页面访问总数，查询参数、IP、浏览器原文和来源地址不进入统计库。原访问日志仍按服务器轮转策略管理。

公开事件端点无法证明每条请求来自真人；这些数据用于产品观察，不能作为身份或付费审计依据。
