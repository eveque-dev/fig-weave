# FigWeave 中文说明

本项目已将默认 [README.md](README.md) 改为中文。请在那里查看 FigWeave 的在线入口、
功能范围、桌面预览安装包、开发步骤与许可证说明。

- 官网：[fig-weave.com](https://fig-weave.com)
- [在线版能力与构建](docs/figweave-online.md)
- [平台支持矩阵](docs/support-matrix.json)：请看 `figweave_distribution`。

当前预览包面向 Windows x64 与 macOS Apple Silicon。Windows ARM 没有构建对应
安装包；Windows 预览包未签名，可能出现 SmartScreen 提示。macOS 预览包未签名、
未公证。完整说明与下载入口统一维护在默认 README。
